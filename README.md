--- Kuizie Q - Interactive Quiz Game

Kuizie Q is a modern comic-style quiz application built using HTML, CSS, and JavaScript. The game provides an engaging user experience with animated UI components, sound effects, timers, score tracking, high-score storage, and educational facts after the quiz.

--- Features

* Interactive quiz interface
* Multiple-choice questions
* 40-second countdown timer
* Dynamic question shuffling
* Sound effects for correct and wrong answers
* Background music
* High score system using Local Storage
* Player name support
* Level selection (Easy, Medium, Hard)
* Educational "Did You Know?" facts section
* Responsive design for mobile and desktop
* Animated modern UI

## 🛠 Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* Local Storage API
* DOM Manipulation

----- How To Play

1. Enter your name.
2. Select difficulty level.
3. Click Start Game.
4. Answer questions before the timer ends.
5. View your final score and educational facts.
6. Try again and beat the high score.
